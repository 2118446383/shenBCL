# 整合包导入与任务恢复

本文记录当前开发版的实现范围。用户提供的 ZIP 已完成真实整包安装、取消后重启恢复及启动预检；完整游戏运行和 Microsoft 外部应用接入尚未完成验收。

## 支持的包

自动导入要求 ZIP / MRPACK 中存在唯一的 `modrinth.index.json`，索引为 Minecraft 的 Modrinth v1 格式。索引可位于根目录或单个外层文件夹中。仅修改后缀不会把普通 ZIP 转成 Modrinth 包。

| 项目 | 当前行为 |
| --- | --- |
| 原版整合包 | 安装索引指定的官方 Minecraft 版本，再导入文件 |
| NeoForge 整合包 | 自动安装标准 Minecraft 1.20 / 1.21 对应的 NeoForge 客户端 |
| Forge / Fabric / Quilt 依赖 | 能解析并展示，但自动安装尚未接入；开始安装前明确拒绝 |
| `overrides/` | 导入通用附带文件 |
| `client-overrides/` | 导入客户端文件，同路径时优先于 `overrides/` |
| `server-overrides/` | 不导入 |
| 客户端 `unsupported` 文件 | 不下载 |
| 客户端 `optional` 文件 | 当前默认包含并显示提示，尚无逐项勾选界面 |
| 已知 PCL / HMCL 设置及账号文件 | 跳过，使用 shenBCL 自己的账号与启动配置 |
| CurseForge `manifest.json`、MultiMC / Prism 导出包、任意文件 ZIP | 尚不支持自动导入；完整已安装客户端可使用目录导入 |

索引中的文件地址支持 `cdn.modrinth.com`、`mediafilez.forgecdn.net`、`edge.forgecdn.net` 和 `media.forgecdn.net` 的 HTTPS 地址，并按适配规则使用 MCIM 备用来源。重定向目标也需符合受控分发规则。支持 CurseForge 文件 CDN 地址不代表具备 CurseForge 清单格式导入能力。索引中的其他来源会明确报错，需要增加经过验证的适配后才能使用。

## 使用流程

1. 打开“导入游戏”选择 ZIP / MRPACK，或直接将一个本机 ZIP / MRPACK 拖入窗口；也可从“下载中心 → 整合包”搜索并下载 Modrinth 整合包。
2. 查看 Minecraft、加载器、模组数量、下载量和 Java 要求，填写新实例名称。
3. 确保已安装对应 Java，然后执行“下载并导入”。同一位置的包若匹配未完成任务，主按钮改为“继续现有安装”；需要独立副本时使用“创建新实例”。当前不自动下载 Java。
4. 等待游戏本体、加载器、模组与配置三个阶段完成。完成后客户端自动加入游戏库并被选中。

预览中的“整合包下载”是索引文件的总大小，不包含游戏本体、加载器及已在 ZIP 内的附带文件；这也不是剩余下载量估算。实际所需空间还包括安装依赖、生成文件和临时文件。

安装创建应用数据目录下的独立实例。它不会把 ZIP 覆盖到已有游戏目录，也不提供自动更新已有整合包的入口。可以关闭导入弹窗继续使用界面，任务仍在后台运行；退出整个启动器会中断任务。

## 取消、失败与重启恢复

正在安装的任务可以取消；错误或取消任务可以从导入面板选择“继续安装”。其他未完成任务也会保留在历史列表中。再次选择或拖入同一个源文件时，会比较源位置、包大小与修改时间、Minecraft 和加载器依赖，优先匹配最近的未完成任务。完成、已移除或这些信息已变化的任务不会匹配。

“取消安装”停止正在执行的工作，保留任务及已校验完整文件，允许稍后继续；出错的历史任务也可改为已取消状态。“移除记录”仅删除任务记录，保留原始 ZIP / MRPACK、实例目录及已下载文件，不执行卸载或磁盘清理。移除后没有该任务的恢复入口；重新选择包会按新任务处理。正在运行的任务须先取消并停止，再移除记录。

- 任务阶段与状态保存到应用数据目录的 `modpack-jobs/`，重启后运行中记录会显示为安装中断。
- 已完成的原版或加载器阶段通常跳过；未完成的阶段重新执行必要检查。
- 模组等完整下载文件按索引哈希和大小重新验证，通过后复用。当前不保存半文件进度，不实现 HTTP Range 续传。
- 原始压缩包必须仍在原位置，且大小、修改时间和依赖保持一致。压缩包改变后需作为新实例重新导入。
- 实例目录及其安装标记必须仍属于原任务。移走实例后在原位置放置其他目录，不能继续往该目录写入文件。
- ZIP 附带配置在恢复文件阶段时会重新导入；不要在任务尚未完成时修改配置或开始游玩。

完成阶段通过基础客户端资源检查后，才会将整个包标记为完成。自动检查能识别缺失的基础文件，不能证明所有模组相互兼容或游戏一定能够进入世界。

## 文件处理规则

下载优先使用 SHA-512，索引仅提供 SHA-1 时使用 SHA-1，同时核对声明大小。索引大小不准确时会失败，尚不支持“哈希正确则忽略大小差异”的兼容策略。下载失败会按索引提供的地址重试并切换来源，默认最多 6 个文件同时下载。

游戏清单、本体、资源库和加载器相关下载接入官方服务与 [BMCLAPI（bangbang93）](https://bmclapidoc.bangbang93.com/)；Modrinth 查询和模组文件接入官方服务与 [MCIM](https://www.mcimirror.top/docs)。主进程统一遵循系统代理，官方来源连接缓慢或不可用时尝试备用来源，限定请求与重定向范围。多源能增加可选下载路径，实际速度仍取决于网络和服务状态，尚无同条件 PCL 对比结果。

下载和解压使用临时文件，校验通过后重命名发布。失败不会将半文件作为正式目标。ZIP 附带文件核对解压大小与 CRC；下载内容核对大小与哈希。`overrides` 按格式规定可以覆盖同路径的索引下载内容，`client-overrides` 再优先于通用覆写文件。

解析器检查路径穿越、Windows 保留设备名、大小写冲突、文件与目录冲突、符号链接及目录联接。包内文件不能覆盖 `versions`、`libraries`、`assets`、Java 运行时目录或应用安装标记。支持 UTF-8 文件名，并对旧式中文 ZIP 文件名尝试 GB18030 解码。

当前限制为最多 100,000 个 ZIP 条目、单文件不超过 2 GiB、索引不超过 8 MiB、声明的安装文件总大小不超过 20 GiB。超过限制或使用加密、损坏、无法解析的内容会明确失败。这些检查旨在约束文件导入，并不构成模组代码审计；启动游戏时，模组仍会作为 Java 代码运行。

不会执行 ZIP 中附带的启动脚本。NeoForge 安装使用官方安装器的 XMCL 工作流，所需 Java 处理器经过来源、路径和运行环境检查后执行。

## 内部记录

默认数据目录保持 `%APPDATA%\Arcane Launcher`，以兼容已有数据。

| 记录 | 用途 |
| --- | --- |
| `modpack-jobs/<UUID>.json` | 私有任务记录，包括源路径、实例位置、阶段与恢复信息 |
| `instances/<名称-短ID>/.arcane-installation.json` | 原版安装状态 |
| `instances/<名称-短ID>/.arcane-modpack.json` | 整个包的名称、状态、依赖和最终客户端版本 |

界面取得预览票据和公开任务状态，不自行决定目标文件路径。新安装开始时会重新检查预览对应的压缩包；预览票据在 30 分钟后失效，需要重新选择。

## 下载中心与单独添加模组

下载中心提供官方 Minecraft 全版本清单、Modrinth 模组及整合包搜索。Minecraft 可筛选正式版、快照与全部版本；模组／整合包可按游戏版本和加载器筛选并选择具体文件。官方清单中的历史版本尚未逐一进行游戏运行验证。

从 Modrinth 下载的 MRPACK 继续使用本文的预览、格式检查和独立实例安装流程。对于已有且已关闭的模组客户端，单独添加模组会递归补齐 Modrinth 标记的必需依赖，匹配实例的游戏版本和加载器；可选依赖不自动安装。全部文件通过大小与哈希检查后再发布到实例，同名相同内容复用，同名不同内容报错，失败或取消会回滚本次新增文件。它不自动升级、删除已有其他版本，也不能替代模组运行兼容性检查。

## 用户样包与验证边界

已只读分析 **Infinity Legacy II 私货版 3.3.6.zip**：

| 字段 | 解析结果 |
| --- | --- |
| 格式 | Modrinth，ZIP 后缀 |
| Minecraft | 1.21.1 |
| NeoForge | 21.1.262 |
| Java | 21 |
| 索引下载文件 | 409 个，696,336,689 字节 |
| 附带导入文件 | 5,273 个，219,184,403 字节 |
| 计划模组文件 | 408 个，含 ZIP 内附带 JAR |

压缩包文件名为 3.3.6，索引的 `versionId` 为 1.0.0；启动器按索引解析，不擅自将文件名当作包内版本。已识别并跳过附带的两个 PCL 配置文件。

自动化测试覆盖格式解析、下载校验、备用来源、路径与重定向限制、取消清理、任务恢复和最终实例扫描。原版安装恢复测试使用真实 XMCL 执行器和受控下载，验证同大小损坏文件会被修复、有效完整文件可复用，并保留玩家配置。尚无同条件 PCL 速度对比数据。

2026-11-16 真实样包已完整安装：Minecraft 1.21.1 / NeoForge 21.1.262、408 个模组、24 个资源包、2 个光影包。下载期间主动取消，保留 2 个已校验模组文件，任务持久化为 cancelled；关闭安装进程后重新启动，恢复原任务并完成。最终实例扫描为 client / ready、issues 为空；Java 21 与真实 XMCL 启动参数预检通过，未启动完整游戏。NeoForge 实测发现并修复了 Electron 手动重定向与 close 事件差异，以及现代 FML 元数据识别。下载中心另已实际下载一个 Sodium 模组，大小与 SHA-512 均与 Modrinth 元数据一致。安装和预检不能替代完整游戏运行验收。

Microsoft 登录、皮肤同步、重启账号恢复和正版启动属于独立验收链路，详见 [Microsoft 接入说明](MICROSOFT_LOGIN.md)；整合包安装完成不能替代这些验收。
