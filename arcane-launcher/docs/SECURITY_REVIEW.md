# shenBCL 0.3.7 复审整改记录

Mojang Enforcement 的回复列出整批应用的审核要求。回复没有指出 shenBCL 被拒绝的单独原因。下表记录旧版中实际查到的缺口、当前实现及审核入口。

| 项目 | 0.3.7 实现与核对位置 |
| --- | --- |
| 游戏所有权 | 删除旧版的本地玩家名、离线 UUID 和替代令牌。客户端和服务端每次启动都经过 Minecraft Services 的 Java 版资格与资料检查。主进程及启动服务均执行校验，创建进程前校验会话是否仍有效。见 account.ts、launch.ts 和 authenticated-launch.test.ts。 |
| 应用身份和认证 | 内置项目所有者注册的 shenBCL 应用标识，移除用户配置和环境变量覆盖。启动时拒绝识别出的认证参数覆盖、Java 代理及非预期参数文件。Forge 服务端要求 online-mode=true。见 microsoft-app.ts、main.ts 和 launch.ts。 |
| 登录和凭据 | 通过固定 Microsoft 官方网址完成设备授权。请求只使用官方端点并禁止跟随重定向。账号记录使用 Windows 加密，界面和导出的启动计划过滤敏感凭据。见 account.ts、main.ts 和 logs.ts。 |
| 有害功能 | 当前界面与 IPC 提供实例、下载、模组安装、存档备份、日志、账号和标准 Forge 服务端管理。源码未提供内置客户端作弊、自动破坏、控制台命令输入、账号获取、联机绕过、AI 执行或 MCP。用户提供的 Java 程序和第三方模组作为本地代码运行，超出启动器自身的审查范围。 |
| 知识产权 | 删除原版下界传送门、黑曜石与版本图标。采用原创环形动效、版本图标和既有 shenBCL 标志。发行包只包含启动器和运行框架，原版清单、游戏文件、依赖与美术资源来自 Mojang 官方端点。见 renderer/assets、PortalScene.vue、download-sources.ts 和第三方许可说明。 |
| 披风 | 预览仅使用在线验证角色官方档案中的活动披风，贴图域和路径有明确限制。需要当前验证才能展示披风。应用未接入披风交易或第三方披风服务。见 account.ts 和 AccountDialog.vue。 |
| 品牌 | shenBCL 使用项目自有名称和图标，关于页面、包元数据及仓库说明标注独立第三方身份。 |
| 审核材料 | 提供同版本的源码、依赖锁、回归测试及构建步骤。新 README 和申请说明按实际流程描述。申请人使用本人有效联系邮箱。见 REVIEW_SUBMISSION.md。 |

复审通过后用真实正版账号检查授权、Minecraft profile 与皮肤／披风、程序重启后的恢复、实际启动、退出后的拒绝和没有所有权账号的拒绝。测试环境使用模拟接口，发行包只包含应用运行文件。
